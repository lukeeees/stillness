# Stillness

**Breathe. Rest. Be.**

A calm, beginner-friendly meditation and mindfulness web app built with Next.js. Designed with a soft blue-green-gray palette, guided voice narration, ambient rain sounds, and a breathing orb to help users reduce stress and improve sleep.

![Stillness Screenshot](https://your-image-link.com/stillness-home.png) <!-- Replace with your own screenshot -->

## ✨ Features

- **Guided Voice Sessions** – Text-to-Speech reads custom meditation scripts with calming pace and tone
- **Ambient Rain Sound** – Toggleable rain background during sessions
- **Gentle Bell Chime** – Plays at the start and end of each session
- **Breathing Orb** – Visual 4-7-8 style breathing guide with animation
- **Box Breathing Exercise** – Quick 4-second inhale/hold/exhale practice
- **Session Library** – 6 beginner-friendly guided meditations (Morning Calm, Body Scan, Evening Wind-Down, Deep Sleep Story, 5-Minute Reset, Gratitude Practice)
- **Progress Tracking** – Streak counter, weekly minutes, and simple chart
- **Clean, Calm Design** – Dark mode only with soft gradients and gentle animations

## 🛠 Tech Stack

- Next.js 14 (App Router)
- React + TypeScript
- Tailwind CSS
- Web Speech API (Text-to-Speech)
- HTML5 Audio API
